# Руководство пользователя

## 🚀 Быстрый старт

### Для Начальника Управления
1. **Dashboard** - начните с обзора KPI и статистики
2. **Реестр задач** - просмотрите все задачи, используйте фильтры
3. **Очередь приемки** - рассмотрите задачи, ожидающие одобрения
4. **Создайте задачу** - нажмите "Создать задачу" в реестре

### Для Сотрудника
1. **Мои задачи** - ваш личный список задач
2. Откройте задачу со статусом "Новая"
3. Нажмите "Взять в работу"
4. После выполнения:
   - Добавьте описание результата
   - Приложите файлы (обязательно!)
   - Нажмите "Отправить на рассмотрение"

## 📋 Основные сценарии

### Работа с задачами

#### Создание задачи (Руководитель)
1. Перейдите в "Реестр задач Управления"
2. Нажмите "Создать задачу"
3. Заполните:
   - Название
   - Описание
   - Исполнитель
   - Дедлайн
   - Отдел

#### Выполнение задачи (Исполнитель)
1. Откройте задачу из "Мои задачи"
2. Нажмите "Взять в работу" (статус: Новая → В работе)
3. Работайте над задачей
4. Перед отправкой на рассмотрение:
   - ✅ Опишите результат
   - ✅ Приложите файлы (минимум 1)
5. Нажмите "Отправить на рассмотрение"

#### Приемка задачи (Руководитель)
1. Перейдите в "Очередь приемки"
2. Откройте задачу
3. Просмотрите:
   - Описание результата
   - Прикрепленные файлы
4. Выберите действие:
   - **Одобрить** → задача закрывается автоматически
   - **Вернуть на доработку** → укажите причину (обязательно!)

#### Доработка задачи (Исполнитель)
1. Задача вернулась со статусом "На доработке"
2. Прочитайте комментарий руководителя
3. Исправьте замечания
4. Повторно отправьте на рассмотрение

### Работа с проектами

#### Создание проекта
1. Перейдите в "Реестр проектов"
2. Нажмите "Создать проект"
3. Заполните информацию о пилоте

#### Ведение статусов
1. Откройте карточку проекта
2. Используйте степпер для изменения статуса:
   - 1️⃣ Реализация платформы
   - 2️⃣ Внутренние тестирования
   - 3️⃣ Согласование условий
   - 4️⃣ Запуск
3. Прикрепляйте документы на каждом этапе

#### Формирование справки
1. В карточке проекта нажмите "Сформировать справку"
2. Система создаст отчет со всеми данными
3. Скачайте или отправьте справку

### Работа с исследованиями R&D

#### Создание исследования (R&D)
1. Перейдите в "База исследований"
2. Нажмите "Создать исследование"
3. Заполните:
   - Резюме
   - Источники
   - Сравнение вариантов
   - Рекомендации
4. Приложите материалы

#### Отправка на рассмотрение
1. Убедитесь, что все материалы приложены
2. Нажмите "Отправить на рассмотрение"
3. Дождитесь одобрения Начальника Управления

#### Открытие доступа (Руководитель)
1. После одобрения исследования
2. Нажмите "Открыть доступ второму отделу"
3. Выберите:
   - Отдел (обычно IT-проекты)
   - Уровень доступа:
     - **Только чтение** - просмотр без изменений
     - **Копирование в проект** - использование в новых проектах
4. Подтвердите

#### Использование исследования в проекте (IT-проекты)
1. Найдите исследование со статусом "Доступ открыт"
2. Откройте карточку исследования
3. Изучите материалы
4. Нажмите "Создать проект на основе исследования"
5. Данные из исследования будут предзаполнены

## 🎯 Фильтры и поиск

### Реестр задач
- **По отделу**: R&D / IT-проекты
- **По статусу**: Новая / В работе / На рассмотрении / На доработке / Принято
- **Только просроченные**: показать задачи с истекшим дедлайном

### Реестр проектов
- **По статусу**: выберите этап проекта (1-4)

### База исследований
- **По статусу**: Черновик / На рассмотрении / Принято / Доступ открыт
- **Только с открытым доступом**: исследования, доступные другим отделам

## ⚠️ Важные правила

### Обязательные вложения
- ❌ Нельзя отправить задачу на рассмотрение без файлов
- ✅ Минимум 1 файл + описание результата
- 💡 Система проверит это перед отправкой

### Комментарии при возврате
- ❌ Нельзя вернуть задачу/исследование без комментария
- ✅ Укажите причину и что нужно исправить
- 💬 Комментарий будет помечен как "Причина возврата"

### Дедлайны
- 🔴 Просроченные задачи подсвечены красным
- 🟡 Задачи "на сегодня" и "завтра" выделены
- 📅 Нет учета часов - только дедлайны

### Права доступа
- 👁️ Read-only: видите, но не можете редактировать
- ✏️ Можете редактировать только в своем отделе
- 👑 Начальник Управления: полный доступ

## 💡 Советы по использованию

### Dashboard
- Кликайте на виджеты для быстрого перехода к отфильтрованным задачам
- Следите за загрузкой сотрудников в таблице
- Процент выполнения показывает эффективность

### Мои задачи
- Задачи автоматически группируются по срочности
- Просроченные всегда сверху
- Используйте быстрые действия прямо из списка

### Очередь приемки
- Все задачи на рассмотрении в одном месте
- Сортировка по дедлайнам
- Быстрый доступ к вложениям

### История изменений
- В каждой карточке есть полная история
- Показывает кто, когда и что изменил
- Помогает отследить весь путь задачи/проекта

- Цветной степпер показывает текущий этап
- Зеленая заливка - пройденные этапы
- Активный этап - цветной
- Будущие этапы - серые

## 📞 Частые вопросы

**Q: Почему я не могу отправить задачу на рассмотрение?**
A: Проверьте, что добавлены вложения и описание результата.

**Q: Где посмотреть все задачи на рассмотрении?**
A: В разделе "Очередь приемки" (только для руководителей).

**Q: Как передать исследование другому отделу?**
A: Сначала его нужно одобрить, затем кнопка "Открыть доступ второму отделу".

**Q: Можно ли изменить статус чужого проекта?**
A: Только ответственный за проект может менять статусы.

**Q: Как скачать все материалы по проекту?**
A: Используйте кнопку "Сформировать справку" в карточке проекта.

## 🎨 Особенности интерфейса

- Все карточки кликабельны - наведите для подсветки
- Модальные окна закрываются кнопкой X или "Закрыть"
- Обязательные поля помечены звездочкой (*)
- Подсказки появляются при наведении на иконки
- Счетчики показывают количество вложений 📎 и комментариев 💬
